# Lire en français · 法语阅读练习

面向 **A2–B2** 法语学习者的阅读练习 App。选择适合自己水平的文章，读完做几道理解题，把想复习的词收进单词本。无需注册，即可开始阅读。

**[打开网页版](https://blog.yosorano.cc/french-reading-app/)** · **[下载 Android 和 Windows 版](https://github.com/dinayuil/french-reading-app/releases)**

## 能做什么

- **分级阅读**。按 A2、B1、B2 筛选文章，也可以在同一篇文章的已发布等级间切换。
- **阅读理解练习**。交卷后查看得分、答案解析和正文依据，并可打开中文对照。
- **标词与复习**。划选法语词语或短语，在文章中做标记、查询中文翻译，或加入单词本。
- **积累学习记录**。设置每日目标，查看阅读与练习用时、完成量和正确率，也可以保存学习统计图片。
- **按习惯阅读**。界面支持法语与简体中文，可选择白天、黑暗或跟随系统主题。

## 选择客户端

- **网页版**在浏览器中直接使用。
- **Android** 下载同一发布页中的 `.apk` 测试包，适用于 Android 7.0 及以上版本。
- **Windows** 下载同一发布页中的 `.exe` 测试安装包，适用于 Windows 10 或 11 的 x64 电脑。

各客户端联网加载文章。学习记录、单词本和设置保存在当前设备，可在「设置」中导出备份并在其他设备导入。Android 和 Windows 安装版也可通过 HTTP 或 HTTPS 连接自己的 WebDAV 文件夹手动同步。主动查询划选翻译时，所选文字会发送给 MyMemory。
